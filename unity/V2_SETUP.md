# Unity V2 - City

1. Create an empty GameObject named City and attach CityGenerator.
2. Create/assign simple road, ground and building materials.
3. Add the player prefab with CharacterController + ThirdPersonPlayer and tag it Player.
4. Add a car prefab with Rigidbody + ArcadeCar.
5. Put WorldSpawn in the scene and assign player/car prefabs and camera.
6. Add a Directional Light and attach DayNightCycle.
7. Traffic cars can use TrafficCar with waypoint transforms.

V2 provides a generated 3D city grid, roads, solid buildings, player/car spawn, traffic routes, building proximity markers and day/night.
