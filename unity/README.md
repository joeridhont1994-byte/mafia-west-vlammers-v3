# Mafia West-Vlammers Unity 3D V1

Unity prototype basis for a GTA-style third-person game.

## V1
- Third-person movement
- Follow camera
- Sprint
- Enter/exit vehicle
- Arcade vehicle driving

Create a Unity 3D project, copy the Assets folder from this directory into it, add a CharacterController to the player and a Rigidbody to the car. Assign the references in the Inspector.
